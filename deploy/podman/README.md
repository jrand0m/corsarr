# Podman Quadlet (rootless)

A systemd user service generated by Podman from `corsarr.container`. The container runs
as uid/gid 65532 mapped to your own user (`UserNS=keep-id`), so media and config you own
are writable without `chown`; root filesystem read-only, no capabilities, built-in health
check, restarted by systemd.

**Prerequisites**: Podman 4.9+ with systemd; `loginctl enable-linger $USER` so the
service runs without a login session.

```sh
mkdir -p ~/.config/containers/systemd ~/.config/corsarr ~/media
cp corsarr.container corsarr-data.volume ~/.config/containers/systemd/
cp corsarr.yml ~/.config/corsarr/
systemctl --user daemon-reload
systemctl --user start corsarr
```

Open http://localhost:8090. Edit the `Volume=%h/media:/media` line for another media path.
Logs: `journalctl --user -u corsarr -f`.

**Config**: [`corsarr.yml`](corsarr.yml), generated from
`corsarr config defaults --format=yaml`. Secrets: `podman secret create name -`, add
`Secret=name,type=env,target=NAME` and reference `${env:NAME}`.

**Data**: the Podman volume `corsarr-data`
(`podman volume inspect corsarr-data --format '{{.Mountpoint}}'`).

**Upgrade**: change the `Image=` tag, `systemctl --user daemon-reload && systemctl --user
restart corsarr`. With `AutoUpdate=registry`, `podman auto-update` does it for a moving tag.

**Backup**:

```sh
systemctl --user stop corsarr
podman volume export corsarr-data > corsarr-data.tar
systemctl --user start corsarr
```
